# Atomic Habits

REST API-сервис для создания и управления полезными привычками.

Проект реализован на Django REST Framework. 
Для выполнения фоновых и периодических задач используется Celery, 
а для отправки уведомлений пользователям — Telegram-бот.

## О проекте

Atomic Habits — сервис для формирования и отслеживания полезных привычек.

Пользователь может:

- создавать привычки;
- редактировать и удалять свои привычки;
- просматривать собственные привычки;
- просматривать публичные привычки других пользователей;
- создавать приятные привычки;
- связывать полезную привычку с приятной;
- указывать место и время выполнения;
- задавать периодичность выполнения;
- указывать вознаграждение;
- получать напоминания о выполнении привычек через Telegram.

Уведомления отправляются автоматически с помощью Celery.

---

## Основные возможности

### Привычки

Для привычки доступны следующие параметры:

- пользователь;
- место выполнения;
- время выполнения;
- действие;
- признак приятной привычки;
- связанная привычка;
- периодичность;
- вознаграждение;
- длительность выполнения;
- признак публичности.

### Типы привычек

**Полезная привычка** — действие, которое пользователь регулярно выполняет.

**Приятная привычка** — привычка, которая может использоваться как вознаграждение за полезную привычку.

Полезная привычка может иметь:

- приятную связанную привычку;
- обычное текстовое вознаграждение.

При этом приятная привычка не может иметь собственную связанную привычку.

# Установка

## 1. Клонирование проекта

```bash
git clone <https://github.com/vadimsemenov53-crypto/Atomic_Habits>
cd Atomic_Habits
```

---

## 2. Установка зависимостей
```bash
poetry install
poetry shell
```

---

## 3. Настройка переменных окружения

Создайте файл .env в корне проекта. (по примеру -> .env.template)

---

## 4. Запуск проекта
Перед запуском необходимо убедиться, что PostgreSQL и Redis запущены.
```bash
python manage.py migrate
python manage.py csu
python manage.py runserver
```

---

## 5. Celery

Запуск Celery Worker, Celery Beat, Redis
```bash
celery -A config worker -l info
celery -A config beat -l info
redis-server
```

---

- Celery Beat
- ↓ 
- создаёт задачу по расписанию 
- ↓ 
- Redis 
- ↓ 
- Celery Worker 
- ↓ 
- выполняет задачу 
- ↓ 
- Telegram Bot API 
- ↓ 
- пользователь получает уведомление

## Telegram-бот

1. Telegram используется для отправки пользователям напоминаний о привычках.

2. Пользователь должен предоставить сервису свой chat_id.

3. После наступления времени напоминания Celery выполняет задачу и отправляет сообщение через Telegram Bot API.

4. Пользователь получает два типа уведомлений:
- За 10 минут до выполнения привычки. 
- В момент начала выполнения привычки.

5. Периодичность привычки учитывается при расчёте следующего времени напоминания.

### Пагинация
Для списков используется пагинация Django REST Framework.

Размер страницы по умолчанию: 5 объектов

Максимальный размер страницы: 10 объектов

Поддерживаются параметры: ?limit=5 , ?offset=0


### Валидация
Для привычек реализованы проверки бизнес-логики.

Основные правила:

- приятная привычка не может иметь вознаграждение;
- приятная привычка не может иметь связанную привычку;
- полезная привычка может иметь либо вознаграждение, либо связанную приятную привычку;
- связанная привычка должна быть приятной;
- время выполнения привычки не должно превышать установленное ограничение;
- пользователь может работать только со своими привычками;
- публичные привычки доступны для просмотра другим пользователям.

Бизнес-правила реализованы на уровне сериализаторов/валидаторов.
